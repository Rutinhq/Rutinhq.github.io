# STORE OS

Sources: https://www.rutinhq.com/store-os · https://docs.rutinhq.com/catalog/store-os/

Shopify Admin audit + config — variants, price, weight, shipping — so the store converts before you buy ads. Delivery mold with a checklist. Named cases live outside the public catalog.

For whom: Founder / ecom lead on DTC Shopify; ops friction; wants ads but the store does not convert yet.

Not for: Theme-only work; ads with no converting store; creatives-only; pure Plus enterprise with no Admin owner.

How: 1) Scorecard / Admin friction diagnosis. 2) Audit: variants, price, weight, shipping. 3) Admin config to the mold (no theme file edits). 4) Delivery checklist + handoff. 5) Ads / creatives = out of scope (NEXUS OS).

Outcomes: store that converts with less ops friction; coherent Admin config; a base ready before ad spend.

What it is not: Theme / Dawn file editing; an ads agency; someone else’s catalog defaults or shipping rates; bots placing purchase orders.
